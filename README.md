# to_words 使用说明

`to_words` 是一款 Windows 快捷词工具。你可以用熟悉的输入法输入文字，从自己的词库中找到对应句子，再复制到聊天窗口、游戏或其他程序。它也支持多语言词库、屏幕文字与语音识别，以及可选的 AI 翻译。

## 开始使用

1. 将拿到的程序文件解压到一个固定文件夹。更新版本时，保留原有的 `word_libraries` 文件夹和 `ui_config.json`，不要用新版文件覆盖自己的词库和设置。
2. 双击 `to_words.exe`。程序会在后台运行，不会立即弹出查询框；可以在 Windows 任务栏右侧的系统托盘找到它。
3. 在需要输入文字的地方按 `Ctrl + Alt + Enter`，打开查询框。

如果你拿到的是项目源码而不是 `to_words.exe`，请参阅 [开发者文档](docs/DEVELOPER.md)。

## 查询和复制

输入你记得的文字，程序会同时搜索词条的原文和译文。按 `↑`、`↓` 选择结果；结果较多时，按 `←`、`→` 翻页。

- 只要一条结果：选中后按一次 `Enter`，复制结果并关闭查询框。回到目标程序按 `Ctrl + V` 粘贴。
- 需要拼接多条结果：选中第一条后按空格，它会出现在输入框下方；继续输入并选择下一条。最后按 `Enter`，一次复制全部结果。复制的各条句子之间会自动加一个空格，末尾不会多加空格。
- 输入框为空时，按 `Backspace` 撤销上一条已拼接结果；按 `Ctrl + Backspace` 清空全部拼接结果。空格前的文字如果没有匹配项，会留在输入框里供你修改，不会加入组合。

例如，词库中有“안녕하세요 → 你好”，输入“你好”就能找到韩文句子。你也可以输入韩文来查找对应的中文。

默认情况下，`Enter` 复制后查询框会关闭。如果希望复制后继续输入，可以在设置中勾选“Enter 复制后仍保持查询框打开”。按 `Esc` 只隐藏查询框；点击查询框右侧的 `×` 会退出整个程序。

## 快捷键与设置

| 默认快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + Enter` | 打开查询框 |
| `Ctrl + Alt + S` | 打开设置 |
| `Ctrl + Alt + O` | 框选屏幕文字并识别 |
| `Ctrl + Alt + V` | 开始或结束语音识别 |
| `Ctrl + Backspace` | 查询框为空时清空拼接结果 |

在设置中可以更改快捷键、查询框外观、每页显示的结果数量，以及原始语言和目标语言。点击快捷键设置项后，直接按下想要的新组合键，再点击“保存并应用”。

程序会根据语言选择使用对应的词库；没有对应文件时会自动创建空词库。原始语言默认为“自动检测”。如果短文字或混合语言匹配到的词库不对，可以在设置中手动指定原始语言。

## 管理自己的词库

按 `Ctrl + Alt + S` 打开设置，点击“编辑词库”。在表格中可以搜索、新增、修改、复制或删除词条，完成后点击“保存”。其中，`key` 列是最终复制的句子，`value` 列是方便搜索的原文或说明。需要处理大量词条时，可以使用批量导入和导出；熟悉 JSON 的用户也可以切换到高级编辑模式。

词库文件保存在程序文件夹内的 `word_libraries` 中。更新 `to_words.exe` 时请保留这个文件夹；程序不会自动生成 `.bak` 备份。如果你有自己的其他词库文件，可以把它放进 `word_libraries`，然后在设置中选择“合并本地词库”。

## 屏幕文字识别（可选）

按 `Ctrl + Alt + O` 后，在屏幕上拖出识别区域。松开鼠标后选区不会消失，会自动识别并在选区下方显示纯文字译文；仍可拖动选区或从右下角调整大小，调整后会重新识别。点击选区右下侧的 `√` 复制识别原文并关闭选区和译文；点击 `×` 或按 `Esc` 取消。

这项功能需要另外安装 [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) 和相应语言包。常用语言包名称：简体中文 `chi_sim`、韩文 `kor`、日文 `jpn`、英文 `eng`。将下载的 `.traineddata` 文件放入 Tesseract 安装目录的 `tessdata` 文件夹；设置页面会显示检测到的语言。详细安装步骤见 [开发者文档的 OCR 部分](docs/DEVELOPER.md#本地-ocr)。

点击 `√` 后，**剪贴板得到的始终是 OCR 识别原文**，译文不会被复制。设置中的“**OCR 识别后自动翻译成原始语言**”默认开启：配置 DeepSeek API Key 后，会将识别文字发送给 DeepSeek，并直接在截图选区下方显示无边框的译文；下方空间不足时显示在上方。原始语言设为“自动检测”时，译成简体中文。截图和 OCR 识别仍在本机完成，**不会上传截图**；但识别文字会通过 API 发送，可能产生费用。关闭该设置时只识别并复制原文，不请求翻译。翻译失败时会在选区旁显示原因，仍可点击 `√` 复制原文。

## 语音识别（可选）

默认使用 whisper.cpp，先按 [语音资源安装说明](assets/voice/README.md) 放好本地识别引擎和多语言模型。按 `Ctrl + Alt + V` 开始录音，说完后停顿约一秒，程序会自动结束这一句、识别并搜索当前词库；也可以再按一次快捷键提前结束。屏幕底部会先显示识别原文，随后在原文下方显示词库结果或 AI 译文。命中词库时默认使用第一条；有多条结果时可在设置中改为打开查询框手动选择。

设置中的“是否保持语音输入”默认关闭。开启后，每次说完一句并停顿约一秒，程序会处理这一句并继续监听下一句；再次按语音快捷键才会停止整个会话。静音检测依赖麦克风音量与环境噪声，复杂环境下仍可用快捷键手动结束。语音识别和网络翻译的实际耗时取决于本机性能与网络，无法保证每次都在两秒内完成。

词库没有匹配项时，如果已启用 DeepSeek、选好目标语言并配置 API Key，程序才会翻译最终识别的文字，并自动将 AI 结果保存到对应语言词库。命中目标语言的 key 时，会输入对应原始语言的 value。语音结果会输入到结果产生时正在使用的窗口当前文本光标处；持续录音期间可以在记事本、浏览器等程序之间切换。为兼容游戏和浏览器，程序会短暂借用剪贴板执行粘贴，然后尽量恢复原内容，不会把译文作为最终剪贴板内容。若剪贴板包含无法安全备份的非文本内容，则改用 Unicode 模拟输入。发送时焦点变化、按住其他组合键，或目标程序阻止模拟输入时不会强行输入；可在系统托盘状态中查看原因。Aion2 若不接受自动输入，可在“语音识别”设置中开启默认关闭的兼容模式：仅当 Aion2 在前台时将结果复制到剪贴板，再由你手动按 Ctrl+V。屏幕下方只显示原文和结果，不显示完成提示；处理完成后保留约 1 秒便自动消失。关闭“多条词库匹配时自动输入第一条”后，手动选择仍沿用查询框的复制流程。

目前随项目放置的 `ggml-base.bin` 模型体积较小，口语短句的准确度可能不如 Windows 自带语音输入。可以按 [语音资源安装说明](assets/voice/README.md) 换用更大的多语言模型；如果总是说同一种语言，也可在设置的“语音识别”中指定识别语言。Windows 本地 AI 识别仍处于实验阶段，普通构建暂不显示该选项，详见[开发者文档](docs/DEVELOPER.md)。

语音耗时日志目前默认关闭，不会继续写入 `logs/voice_metrics.jsonl`；已有日志不会被自动删除。

## AI 翻译（可选）

在设置中启用 DeepSeek 翻译，并填入自己的 API Key。需要翻译时，在查询框输入文字后按 `Ctrl + Enter`，或点击“使用 DeepSeek 翻译”；程序不会因为本地词库没有结果就自动请求 AI。使用 API 可能产生费用。

输入原始语言时会翻译成目标语言；输入目标语言时会反向翻译成原始语言。“自动检测”模式下，反向翻译默认使用简体中文。查询框中确认译文后，默认会同时保存到对应词库；这项自动保存可在设置中关闭。语音的 AI 译文则按语音流程自动收录。API Key 保存在当前 Windows 用户的凭据管理器中，不写入词库或设置文件。

## 托盘与常见问题

右键系统托盘图标，可以打开查询框、打开设置、重新加载词库或退出程序。

- 按快捷键没反应：先确认托盘图标还在；若快捷键与其他程序冲突，可从托盘打开设置并更换组合键。
- 查询不到词条：检查设置中的原始语言和目标语言，并确认当前词库已有内容。
- OCR 识别不出中文、韩文或日文：检查是否安装了对应语言包，可在设置中查看已识别的语言。
- 查询框没有出现在光标附近：有些程序或游戏不会提供光标位置，工具会回退到当前显示器的左下方。

需要构建、发布或查看文件格式与实现细节，请阅读 [开发者文档](docs/DEVELOPER.md)。
